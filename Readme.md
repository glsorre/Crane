# Crane

Crane is a native MacOS app to manage Apple containers.

!["containers list"](screenshots/screenshot_001.png)

## Roadmap

- [X] containers listing grouped by network
- [X] basic containers management (play, stop, remove)
- [X] containers listing polling
- [X] containers logs grouped by handle
- [X] containers logs polling
- [X] volumes listing
- [X] images listing
- [ ] volumes creation
- [ ] images fetching
- [ ] networks creation
- [ ] containers creation
- [ ] launch container apiserver at launch
- [ ] ...
